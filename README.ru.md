# Constellation — живой граф связей для SilverBullet

[English version](README.md)

Constellation показывает базу [SilverBullet](https://silverbullet.md) графом, который выглядит живым:
- узлы плавно покачиваются;
- соседи тянутся за перетаскиваемым узлом, остальные расступаются.

При этом раскладка не «скачет»: при каждом открытии и переходе между страницами граф остаётся там, где вы его
оставили.

Нажмите на узел — откроется карточка со страницей: текст, запросы, виджеты и **работающие галочки задач**.
Отмечать задачи можно, не выходя из графа.

![Граф в тёмной теме](docs/graph-dark.png)

![Карточка страницы с задачами](docs/card-light.png)

## Возможности

- **Два вида**: на весь экран (**Constellation: Open Graph**) и сбоку от заметки (**Constellation: Toggle Side Graph**).
- **Разделы с цветами** и легенда-фильтр. Разделы можно задать по папкам. Без настройки раздел — это папка верхнего
  уровня.
- **Карточка страницы**:
  - содержание с выполненными вставками `${…}` (запросы, виджеты);
  - связанные страницы и кнопка «Открыть заметку»;
  - **галочки задач пишутся прямо в заметку**, в том числе у задач из запросов с других страниц.
- **Лента времени**: ползунок показывает только страницы за последние N дней. Свежие страницы ярче, давние бледнее.
- **Отметки**: красное кольцо у страниц с просроченными задачами, «через N дн.» у ближайших мероприятий.
- **Связи из атрибутов задач**: `[who: Анна]` может связать страницу с `Люди/Анна`, и у людей не будет «сирот».
- **Созвездия**: страницы об одном и том же собираются и светятся туманностями, у каждой свой цвет и название
  (нажмите на название — приблизить, наведите — подсветить страницы). Ищутся по ссылкам между страницами *и* по
  схожести текстов (TF-IDF, считается в браузере и запоминается, пока страница не изменится). Итоги дня и недели
  не участвуют: они связаны со всем подряд. По желанию — тонкие нити между похожими, но не связанными страницами.
- Режим «Рядом» (от одного до трёх шагов от выбранной страницы), поиск, страницы без связей по кнопке.
- **Настройки** (⚙):
  - движение: плавают, спокойно или неподвижно; отталкивание, длина связей, притяжение к центру;
  - созвездия: туманности вкл/выкл, яркость, мягкость краёв, цвет (свой или по разделу), названия, баланс
    «связи ↔ текст», строгость, размер созвездий, наименьшее созвездие, стягивание, нити схожести;
  - узлы — кружки или **звёзды**: раскалённое белое ядро, сияние цвета раздела и лучи, чем больше связей — тем крупнее
    звезда (сияние, лучи и ядро настраиваются);
  - размер узлов (по связям или одинаковый), толщина и яркость связей, звёздный фон, мерцание, приглушение при наведении;
  - подписи: какие показывать, яркость, размер;
  - цвета разделов, яркость по ленте времени, отметки, открытие при запуске.
- Интерфейс на русском и английском. Светлая и тёмная тема (переключается вместе с SilverBullet на лету).
  Работает на сенсорном экране.
- У каждой базы на одном сервере (многопользовательский SilverBullet) своя память раскладки.

## Установка

В SilverBullet выполните **Library: Install** и введите:

```
ghr:TeenKode/silverbullet-constellation/PLUG.md
```

Так ставится последний [релиз](https://github.com/TeenKode/silverbullet-constellation/releases). Обновление —
**Library: Update**. Чтобы брать версию из ветки `main`: `github:TeenKode/silverbullet-constellation/PLUG.md`.

Вручную: положите `constellation.plug.js` в любую папку базы (например, `Library/TeenKode/`) и выполните
**Plugs: Reload**.

Нужен SilverBullet 2.10 или новее. При каждом изменении плагин проверяется на SilverBullet 2.11.1.

## Как пользоваться

| | |
|---|---|
| **Constellation: Open Graph** | граф на весь экран; повторный вызов или Esc закрывает |
| **Constellation: Toggle Side Graph** | граф сбоку; нажатие на узел открывает страницу |
| Нажатие на узел (на весь экран) | карточка страницы |
| Наведение на ссылку в карточке | подсвечивает эту страницу в графе |
| Esc | очищает поиск, затем закрывает настройки, карточку и граф |

Кнопка на панели действий (в блоке `space-lua`):

```lua
actionButton.define {
  icon = "share-2",
  description = "Граф связей",
  run = function() editor.invokeCommand("Constellation: Open Graph") end,
}
```

Русское имя команды, если нужно:

```lua
command.define {
  name = "Граф связей: открыть",
  run = function() editor.invokeCommand("Constellation: Open Graph") end,
}
```

## Настройка

Всё необязательно. Настройка — в блоке `space-lua`, например на странице `CONFIG`:

```lua
config.set("constellation", {
  language = "ru",
  openOnStart = true,
  groups = {
    { id = "topic",  name = "Темы",        one = "Тема",        prefix = "Темы/" },
    { id = "event",  name = "Мероприятия", one = "Мероприятие", prefix = "Мероприятия/" },
    { id = "person", name = "Люди",        one = "Сотрудник",   prefix = "Люди/", undated = true },
    { id = "day",    name = "Итоги дня",   prefix = "Итоги дня/", color = "#22c55e", darkColor = "#4ade80" },
    { id = "other",  name = "Другое",      one = "Страница" },
    { id = "service", name = "Служебное",  prefix = { "Служебное/" }, pages = { "index" }, hidden = true, undated = true },
  },
  taskLinks = { who = "Люди/" },
  dueAttributes = { "due" },
  upcoming = { attribute = "date", days = 14, prefix = "Мероприятия/", mirror = "Темы/" },
})
```

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `language` | `"auto"` | `"ru"`, `"en"` или `"auto"` (язык браузера) |
| `openOnStart` | `false` | открывать граф на весь экран, когда база открывается на стартовой странице; в каждом браузере можно поменять в ⚙ |
| `startPage` | `"index"` | стартовая страница (для `openOnStart` и подписи «Главная») |
| `homeLabel` | `"Главная"` | подпись узла стартовой страницы |
| `groups` | папка верхнего уровня | список по порядку, срабатывает первый подходящий. `prefix` — строка или список, `pages` — точные имена. `color`/`darkColor` — цвета, `hidden` — скрыт по умолчанию, `undated` — не участвует в ленте времени. Страницы вне разделов попадают в `other`; `{ id = "other", … }` задаёт его название и место в легенде. |
| `taskLinks` | `{}` | атрибут задачи → префикс страницы. `[who: Анна, Олег]` связывает страницу задачи с `Люди/Анна` и `Люди/Олег`. |
| `dueAttributes` | `{"due", "deadline"}` | атрибуты задачи со сроком (`ГГГГ-ММ-ДД`) для кольца просрочек |
| `upcoming` | `{attribute = "date", days = 14}` | страницы с датой в `attribute` в ближайшие `days` дней получают «через N дн.». `prefix` ограничивает папкой. `mirror` отмечает и одноимённую страницу в другой папке (тему мероприятия). `false` выключает отметки. |
| `exclude` | — | ещё страницы, которые не показывать: префиксы `"Папка/"` или точные имена. `Library/`, `Repositories/`, `_…`, `CONFIG`, `PLUGS`, `SETTINGS`, `SECRETS` скрыты всегда. |
| `similarity` | `true` | читать тексты страниц, чтобы находить страницы об одном и том же (созвездия). `false` — только ссылки, тексты не читаются. |
| `similarityMaxPages` | `1500` | если страниц больше, тексты не читаются |
| `extraCss` | `""` | дополнительный CSS для панели графа, например стили своих виджетов в карточке |

Даты для ленты времени:
- страница с именем-датой (`Итоги дня/2026-09-28`) — этот день;
- с именем-неделей (`Итоги недели/2026-W39`) — понедельник этой недели;
- остальные страницы — время последнего изменения.

Настройки браузера (⚙, фильтры легенды, лента времени) хранятся в браузере. «Сбросить настройки» в ⚙ возвращает
стандартные.

## Разработка

```shell
npm install
npm test                 # юнит-тесты (node --test)
npm run build            # → constellation.plug.js
node scripts/check.mjs   # проверка в настоящем SilverBullet через Playwright
```

`scripts/check.mjs`:
- скачивает SilverBullet (`SB_VERSION`, по умолчанию 2.11.1) или берёт `SB_BIN`;
- собирает демо-базу (`scripts/demo-space.mjs`);
- `CHROME_BIN` задаёт свой Chromium, `SCREENSHOTS=docs` обновляет картинки README.

Файлы:
- `src/core.ts` — чистая логика: настройка, подписи, места задач, данные графа;
- `src/constellation.ts` — функции плагина;
- `assets/graph-render.js` — отрисовка (d3 в iframe панели).

Выпуск:
1. Поднимите `version` в `package.json`.
2. Отправьте тег `v<версия>` или запустите workflow **Release** с галочкой «release».
3. Сборка проверит плагин и опубликует `constellation.plug.js` и `PLUG.md`.
